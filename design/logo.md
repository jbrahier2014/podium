# Logo

## The mark

Three square blocks — second, first, third — and a dot over the tallest. The blocks are always the same ink as the wordmark; the dot is always `brand-violet` (#7C5CFF), except in one-colour use. The blocks never change order or height.

## Versions

| Version | When |
| --- | --- |
| Lockup (mark + wordmark) | Default. App header, website, partner placements. |
| Stacked | Splash screens, square spaces, social avatars with room. |
| Mark | Favicon, small spaces, when "Podium" is already written nearby. |
| App icon | White mark on a full `brand-violet` field. |

## Colour

- On light grounds: ink `#111214` + violet dot.
- On dark grounds: `#F5F5F2` + violet dot.
- On `brand-violet`: all white.
- One colour (print, embroidery, emboss): every part in a single ink, dot included.
- On photography: reversed version over a dark scrim, never directly on a busy image.

## Size and space

- Minimum height: lockup 20px (12mm in print), stacked 48px, mark 16px.
- Clear space on all sides: at least the dot's diameter (the mark's height × 0.2). In the lockup, the gap between mark and wordmark is fixed — never re-space it.

## Don't

- Recolour the blocks violet or the dot any colour but violet, white or the single ink.
- Stretch, rotate, outline, add shadows, gradients or bevels.
- Re-type the wordmark in a live font — use the files or the `Logo` component.
- Rearrange the blocks into a chart or add a fourth block.
- Lock the logo up with a tagline, a sport, or a partner's logo inside the clear space.
